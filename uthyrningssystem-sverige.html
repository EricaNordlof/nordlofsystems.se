Vanliga frågor

Det praktiska först.

Är ett kundanpassat system alltid dyrare?+

Inte om uppdraget avgränsas rätt. Det kan vara billigare att lösa ett viktigt gap än att betala för ett stort standardsystem som ändå kräver manuella sidoflöden.

Kan ni integrera ett befintligt system?+

Ja, om systemet har ett användbart API eller andra säkra integrationsmöjligheter.

Kan arbetet genomföras helt på distans?+

Ja. Nuläge, regler, skisser, tester och leveranser kan hanteras med skriftligt underlag och korta planerade avstämningar.
