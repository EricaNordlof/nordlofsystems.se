# Nordlöf Systems — premiumwebbplats

Färdig statisk webbplats för nordlofsystems.se. Nordlöf Systems är ett varumärke inom Nordlöf Nordic, enskild firma.

## Publicera på GitHub Pages

1. Registrera först domänen nordlofsystems.se.
2. Packa upp ZIP-filen.
3. Lägg filerna direkt i roten av repositoryt för nordlofsystems.se.
4. Publicera från main och /(root) i GitHub Pages.
5. Behåll CNAME-filen när domänen är registrerad och DNS är kopplad.

Ingen byggprocess krävs.

## Innehåll

- Mörk premiumdesign i riktningen Dark Technical Atelier.
- Startsida, tjänster, lösningar, case, om, samarbete, kontakt, integritet och villkor.
- 18 innehållsrika SEO-sidor för uthyrningssystem, branscher och utvecklartjänster.
- Mobilmeny, tangentbordsstöd, reducerad rörelse och tydliga fokusmarkeringar.
- Canonical, Open Graph, JSON-LD, sitemap.xml, robots.txt och llms.txt.
- Premiumlogotyp, favicon och social delningsbild i SVG.
- CNAME för nordlofsystems.se.
