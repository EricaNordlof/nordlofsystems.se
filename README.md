# Nordlöf Systems — företagssajt, CV och portfolio

Färdig statisk webbplats för `nordlofsystems.se`. Nordlöf Systems är ett varumärke inom Nordlöf Nordic, enskild firma, och sajten fungerar samtidigt som Erica Nordlöfs CV och tekniska portfolio.

## Publicera på GitHub Pages

1. Packa upp ZIP-filen.
2. Lägg filerna direkt i roten av repositoryt `nordlofsystems.se`.
3. Publicera från `main` och `/(root)` i GitHub Pages.
4. Behåll `CNAME` och befintliga DNS-poster för `nordlofsystems.se`.
5. Aktivera `Enforce HTTPS` när GitHubs DNS-kontroll är grön.

Ingen byggprocess krävs.

## Viktigt före lansering

- Skapa eller vidarebefordra `erica@nordlofsystems.se` i Loopia så att kontaktlänkar och formulär når rätt inkorg.
- Kontrollera LinkedIn-länken efter publicering.
- När den nya sajten fungerar: vidarebefordra `webutvecklare.se` permanent till `https://nordlofsystems.se/` och behåll vidarebefordran i minst ett år.
